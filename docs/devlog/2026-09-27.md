## Learned

- `pnpm-workspace.yaml`:
  - It tells pnpm which folders hold packages, such as `apps/*` and `packages/*`.
  - It also defines a catalog, a single place to set a dependency's version for all packages (e.g., typescript: ~6.0.3).

- `package.json`:
  - One exists at root and one in each package; each holds its own scripts, `dependencies` and `devDependencies`.
  - A package that lists a dependency as `"catalog:"` gets the version set in `pnpm-workspace.yaml`.

- `turbo.json`:
  - It sets the order tasks run in, also controls caching.
  - Specifically, which tasks depends on which (e.g., `dependsOn: ["^build"]`) and which `outputs` get cached.
  - `^` in `^build` means run build in this package's dependencies first.
